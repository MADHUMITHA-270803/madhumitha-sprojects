# 🎉 QuizCraft — HTML, CSS & JavaScript

A fun and interactive **Quiz Application** built using **pure HTML, CSS, and JavaScript** — no frameworks or libraries required! You can use this to test knowledge on any topic and customize it with your own questions.

This project is based on the *Build Quiz App* tutorial from CodingNepal. The app includes features like a **timer**, **progress display**, and **results screen** to make the experience smooth and engaging. :contentReference[oaicite:0]{index=0}


---

## ⭐ Features

- ✔️ Simple quiz with **multiple choice** questions  
- ⏱️ **Timer** for each question  
- ✅ Displays correct/incorrect answer instantly  
- 📊 Shows final **score and results**  
- 🔁 Replay functionality  
- 🎨 Clean & responsive UI  
- Fully customizable questions and styles

---

## 🛠️ Technologies Used

- **HTML** — for app structure  
- **CSS** — for styling and animations  
- **JavaScript** — for quiz logic and interaction
